About Loomfit

README, pulled from the project repository.

# Loomfit

Loomfit is a smart shortlisting engine built for the InternLoom AI Hackathon.
It ranks a batch of resumes against a single job description using a
combination of semantic search and keyword matching, and produces an
explainable, ranked shortlist rather than a single opaque score.

## What it does
- Parses resumes (PDF/DOCX/TXT) and a job description
- Scores every candidate using semantic similarity + keyword overlap
- Weights experience-backed skills over skills-only mentions
- Produces plain-language explanations for the top 3 candidates
- Lets a recruiter ask the built-in assistant why a candidate ranked where they did

## Stack
FastAPI backend, sentence-transformers for semantic scoring, regex/keyword
matching for explicit skills, Ollama running Qwen2.5-3B-Instruct for
natural-language explanations, plain HTML/JS frontend.

## Status
Built for a timed hackathon submission. Core ranking pipeline complete;
chat explanation layer connected via local Ollama instance.
